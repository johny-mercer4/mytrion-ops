# Owner card management

- This skill is only for a verified owner or manager.
- Read the exact live card first, summarize the requested change, and require explicit confirmation.
- Execute activation, deactivation, or limit changes only after confirmation.
- Report the tool result; never claim success from the request alone.
- When the owner or manager asks for the live Card Lookup/card-list report, use
  `octane_card_lookup_report` and send PDF or Excel to their private bot chat. Report delivery
  does not require a confirmation button.
