# Transactions and reports

- Drivers receive only their registered card’s transactions; owners may choose fleet or one card.
- Inline group results contain no dollar figures.
- Reports with monetary detail go only to the verified user’s private bot chat.
- State the period and scope explicitly, and never invent missing transactions.
- Treat consecutive Telegram fragments as one intake: collect scope (fleet/card/unit), period,
  format, and requested price columns before running a report. If one required field remains
  unclear, ask one focused question; never launch multiple reports for the fragments.
